## مخطط ورقة `Menu`

تمت معاينة صف العناوين في الورقة، ويحتوي على الحقول التالية:

| العمود | الحقل | الاستخدام |
| --- | --- | --- |
| A | كود الصنف | معرّف المنتج |
| B | اسم الصنف | اسم المنتج |
| C | سعر الكاش | السعر النقدي |
| D | سعر البيع قسط | سعر التقسيط |
| E | الكمية | المخزون |
| F | التوافر | حالة التوفر |
| G | رابط الصورة | رابط الصورة (اختياري) |
| H | التصنيف | تصنيف المنتج |
| I | الوصف | وصف المنتج |
| J | العلامة التجارية | العلامة التجارية |

الحقول `التصنيف` و`الوصف` و`العلامة التجارية` اختيارية في التوافق الخلفي، لكنها موجودة بالفعل في الورقة. الإصدار `5.1.0` من `Code.gs` يقرأها ويكتبها، ويزيد إصدار الكاش حتى لا يعيد بيانات الإصدار السابق. تبقى الحقول الستة الأولى مطلوبة. كما صُحح معرّف الجدول في `Code.gs` ليتطابق مع الرابط أعلاه.

بعد نشر `Code.gs` كتحديث لإصدار Google Apps Script الحالي، ستظهر التصنيفات في شريط الفلترة، كما ستظهر بيانات الوصف والعلامة التجارية في بطاقة المنتج وتفاصيله. تدعم لوحة الإدارة تحرير الحقول وإرسالها مع عمليات الإضافة والتحديث. تحقق من أن واجهتي المتجر والإدارة تستخدمان رابط النشر نفسه بعد التحديث؛ الرابطان الموجودان حاليًا يشيران إلى عمليتي نشر مختلفتين.

نتيجة فحص النشر الحالي: رابط المتجر يرد بالإصدار `4.3.0` ولا يرسل حقول التصنيف والوصف والعلامة التجارية. رابط الإدارة يرد بخطأ لأن النشر يتوقع العنوان `سعر البيع قسط شهري` بدل العنوان الموجود `سعر البيع قسط`. انشر الكود المحدّث، ثم حدّث رابط `API_URL` في الواجهتين إلى رابط النشر المتوافق.

ملاحظة فحص: الخلية `K1` تحتوي قيمة وقت/تاريخ وليست عنوان حقل، والخلايا المقابلة التي فُحصت فارغة؛ لم تُعدّل بيانات الجدول.
